## Implementation

- `src/geo.py`: one UTM frame for pixels, streets, routes and terrain.
- `src/graph.py`: directed shortest paths, bounded snapping/detours, curved edges,
  rejection of disconnected/degenerate routes. No straight-line fallback.
- `src/images.py`: lazily loaded SD 1.5, experimental Canny ControlNet, validated settings.
- `src/generation.py`: shared pipeline, intermediate images, timings, GPX.
- `src/web.py`: Gradio UI mounted on FastAPI; `create_site()` also serves `/about`.
- `src/map_view.py`, `src/terrain.py`, `src/assets/`: SVG map, terrain, elevation profile,
  query-enabled dialogs and responsive styles.
- `scripts/prepare_map.py`, `scripts/prepare_terrain.py`: offline map/terrain preparation.
  Prepared artifacts are in `data/`, with provenance and hashes. Do not rebuild unnecessarily.
  Current graph: 15,701 nodes and 38,573 directed edges.
- `scripts/modal_app.py`: GPU web deployment and separate controlled comparison.
  Dependencies are installed before source copies so code changes reuse the large layer.
- `src/experiment.py`: six prompts × seeds 0/1 × strengths 0/0.1/0.3.
  A baseline-only mode evaluates 12 images. Saves images, outlines, successful
  overlays/GPX, timings, statuses, prompt template, map frame and graph hash.
